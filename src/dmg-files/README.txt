# nas迅雷 客户端

## 简介

nas迅雷客户端是 Synology NAS 上迅雷下载站的桌面封装客户端，支持磁力链接、ed2k、thunder/ftp 协议一键下载。

## 安装方法

1. 将左侧的 **nas迅雷** 拖到右侧的 **Applications** 文件夹
2. 打开「启动台」或「应用程序」文件夹，找到 nas迅雷 并打开

## 首次打开提示"无法打开"或"已损坏"怎么办？

由于本应用未经 Apple 开发者签名，macOS 会阻止打开并提示"无法验证开发者"或"已损坏"。

### 方法一：使用本 dmg 内的修复脚本（推荐）

双击本 dmg 里的 **修复无法打开.command** 文件，按提示输入 Mac 登录密码即可自动修复。

### 方法二：手动操作

1. 打开「系统设置」→「隐私与安全性」
2. 在下方找到提示 "nas迅雷" 已被阻止，点击「仍要打开」
3. 或在「应用程序」文件夹中**右键点击** nas迅雷 → 选择「打开」→ 在弹窗中点击「打开」

### 方法三：终端命令

打开「终端」应用，粘贴以下命令并回车（可能需要输入 Mac 登录密码）：

```
sudo xattr -cr /Applications/nas迅雷.app
```

## 卸载

将「应用程序」中的 nas迅雷 拖到废纸篓即可。

## 支持的链接协议

- magnet: （磁力链接）
- ed2k:// （电驴链接）
- thunder:// （迅雷链接）
- thunderx:// （迅雷链接）
- ftp:// （FTP 链接）

在浏览器中点击上述协议的链接，会自动唤起 nas迅雷 客户端并弹出下载窗口。
